# AI Handover Index

Protocol: AI-HANDOVER/V2

Start here:

1. `STATE.yaml`: compact truth snapshot
2. `HANDOVER.md`: quick summary
3. `CURRENT_STATE.md`: detailed present state
4. `PENDING.md`: remaining work
5. `NEXT_AGENT.md`: exactly what to do first

Read only when referenced:

- `PROJECT_CONTEXT.md`: goal, rules, user preferences, conventions
- `ISSUES.md`: known traps and failed approaches (read before debugging CI or tests)
- `CHANGES.md`: what each merged PR did
- `DECISIONS.md`: choices that shape future work
- `TESTING.md`: verification evidence

The repository's own docs stay authoritative for design: `CLAUDE.md`,
`docs/05-atomic-assist-plan.md` (plan, §36 checklist) and
`PROJECT_OVERVIEW.md` (as built). This folder is the session continuity
layer, not a copy of them.
